### Multi-Tenant Mobile Platform

Developed while at NE Innovation Labs, this project is a sophisticated geospatial mobile platform that enables location-aware user experiences and regional commerce engagement.

**Key Technical Achievements:**

*   **Real-time Infrastructure:** Designed a system supporting 1,000+ concurrent users per region using Redis and Serverpod for reliable cross-node communication.
*   **Geospatial Logic:** Implemented complex geospatial event triggers using PostGIS to enable dynamic, location-based interactions.
*   **Scalable Multi-tenancy:** Architected the system to support isolated gameplay and commerce systems for multiple tenants on a single infrastructure.
*   **AI-Enhanced Workflow:** Leveraged AI to automate tenant-specific configurations, reducing onboarding time by 35%.
*   **Cloud-Native Deployment:** Deployed on AWS ECS with RDS (PostgreSQL) and Redis for high availability.
